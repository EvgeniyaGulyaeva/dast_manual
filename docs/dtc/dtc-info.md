# Просмотр данных диагностического кода события (ДКС)

Нажатие на код ДКС в [списке](docs/dtc/index.md#журнал-событий) открывает страницу с подробной информацией о выбранном коде события. 

Страница ДКС является отправной точкой для анализа первопричины события. Она предоставляет минимально необходимый, но достаточный набор данных, полученных непосредственно от автомобиля, и позволяет диагносту самостоятельно:

- определить условия возникновения события;
- оценить влияние события на работу автомобиля;
- проанализировать параметры, предшествовавшие регистрации ДКС;
- принять решение о дальнейших диагностических действиях.

## Общая информация о диагностическом коде события

**Пример отображаемых параметров**:

| Параметр | Описание | Пример |
| :------ | :------ | :------ |
| **Диагностический код события** | Стандартизированный код, генерируемый бортовой системой OBD-II при обнаружении проблемы. Ознакомиться со списком кодов ДКС и их описаниями можно на портале послепродажного обслуживания. | C15101A |
| **Статус ДКС** | **Активный** — выявлен в ходе текущего считывания ДКС;<br></br>**Сохраненный** — выявлен ранее, но не подтвержден в текущем тесте самодиагностикой ЭБУ | Активный / Сохраненный |
| **Описание ДКС** | Краткое описание кода события | Сопротивление электропитания передней подушки безопасности водителя ниже порогового значения |
| **Условия появления ДКС** | Условия, при соблюдении которых в ходе диагностики фиксируется ДКС | Сопротивление не превышает 0,56 Ом, и длится более 4 с |
| **Условия перехода ДКС в статус «Сохраненный»** | Условия, при соблюдении которых ДКС переходит из статуса «Активный» в статус «Сохраненный» | Сопротивление превышает 1,6 Ом в течении более 8 с |
| **Приоритет** | Степень влияния на функционирование системы | Высокий / Средний / Низкий |
| **Влияние на функции автомобиля** | Описание возможного влияния на функционирование системы | Нет влияния |
| **Информирование водителя** | Указание на информирование водителя о зарегистрированном событии с использованием средств информирования водителя (визуальная и/или звуковая индикация, текстовое или голосовое сообщение и др.) | Да / Нет |


## Параметры на момент события 

Параметры на момент события — это набор дополнительных параметров, сохраненных в момент регистрации ДКС. Эти данные играют вспомогательную, но критически важную роль при диагностике.

Параметры на момент события включают:
- **стандартные** параметры — поддерживаются всеми ЭБУ, способными сохранять ДКС;
- **расширенные** параметры — специфичны для конкретного ЭБУ и поддерживаются не всегда.

Пример отображаемых параметров приведен в таблице ниже.

:::warning
Поддерживаемый набор параметров определяется диагностической спецификацией конкретного блока управления.
:::

| Параметр | Пример значения |
| :------- | :------- | 
| Дата события | 25.12.2025 |
| Пробег | 27456 км|
| Напряжение бортовой сети | 12,8 В|
| Скорость автомобиля | 38 км/ч|
| Состояние автомобиля | Drive-Normal |
| Включенная передача | D |
| Состояние ВВ системы | Standby |
| Заряд ВВ батареи | 42% | 

:::note
Если для диагностического кода события доступна ведомая диагностика, нажмите на кнопку в верхнем правом углу страницы ДКС и перейдите к Руководству по ведомой диагностике.


:::

## Ведомая диагностика

Для некоторых ДКС в АТОМ ДИС доступна **ведомая диагностика** — сервисная операция, предназначенная для поиска и устранения причин возникновения кода неисправности.

Чтобы запустить ведомую диагностику, нажмите кнопку **Ведомая диагностика** на странице ДКС и последовательно выполняйте шаги сервисной операции, следуя инструкциям на экране.

## Поиск причин неисправности

В разделе **Поиск причин неисправности** отображается информация о способах проверки и устранения неисправностей, соответствующих выбранному ДКС. 

Рекомендации и ремонтные действия доступны для тех ДКС, для которых уже подготовлена и проверена информация по диагностике и устранению неисправности.
