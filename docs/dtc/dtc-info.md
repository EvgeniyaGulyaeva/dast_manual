# Просмотр данных диагностического кода неисправности (DTC)

Нажатие на код DTC в [списке](docs/dtc/index.md#список-dtc) открывает страницу с подробной информацией о выбранном коде неисправности. 

Страница DTC является отправной точкой для анализа первопричины неисправности. Она предоставляет минимально необходимый, но достаточный набор данных, полученных непосредственно от автомобиля, и позволяет диагносту самостоятельно:

- понять условия возникновения ошибки;
- оценить влияние неисправности на работу автомобиля;
- проанализировать события, предшествовавшие ошибке;
- принять решение о дальнейших диагностических действиях.

:::note
В отличие от плана проверок (ведомого поиска неисправностей), страница DTC не предлагает пошаговых инструкций для диагностики и устранения неисправности, а предоставляет фактические данные для аналитической работы. 
:::

Используйте страницу DTC для следующих задач:
- просмотр детальной информации о коде неисправности, считанном с автомобиля;
- анализ стоп-кадра данных, зафиксированных в момент события;
- переход к пошаговому плану проверок (если доступен).

## Общая информация о диагностическом коде неисправности

Пример отображаемых параметров представлен в таблице ниже.

| Параметр | Описание | Пример |
| :------ | :------ | :------ |
| **Диагностический код неисправности** | Стандартизированный код, генерируемый бортовой системой OBD-II при обнаружении проблемы <mark>можем ли мы предложить референс на какую-нибудь документацию?</mark>| C15101A |
| **Статус DTC** | **Активная** — выявлен в ходе текущего считывания DTC; **Сохраненная** — выявлен ранее, но не подтвержден в текущем тесте самодиагностикой ЭБУ | Активная / Сохраненная |
| **Описание DTC** | Краткое описание кода неисправности | Сопротивление электропитания передней подушки безопасности водителя ниже порогового значения |
| **Условия появления DTC** | Условия, при соблюдении которых в ходе диагностики фиксируется DTC | Сопротивление не превышает 0,56 Ом, и длится более 4 с |
| **Условия перехода DTC в статус «Сохраненная»** | Условия, при соблюдении которых DTC переходит из статуса «Активная» в статус «Сохраненная» | Сопротивление превышает 1,6 Ом в течении более 8 с |
| **Приоритет** | Степень влияния на функционирование системы | Высокий / Средний / Низкий |
| **Влияние на функции автомобиля** | Описание возможного влияния на функционирование системы | Нет влияния |
| **Информирование водителя** | Указание на информирование водителя о зарегистрированном событии с использованием средств информирования водителя (визуальная и/или звуковая индикация, текстовое или голосовое сообщение и др.) | Да / Нет |
