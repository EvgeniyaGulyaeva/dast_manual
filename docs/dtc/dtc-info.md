# Просмотр данных диагностического кода неисправности (DTC)

Нажатие на код DTC в [списке](docs/dtc/index.md#список-dtc) открывает страницу с подробной информацией о выбранном коде неисправности. 

Страница DTC является отправной точкой для анализа первопричины неисправности. Она предоставляет минимально необходимый, но достаточный набор данных, полученных непосредственно от автомобиля, и позволяет диагносту самостоятельно:

- понять условия возникновения ошибки;
- оценить влияние неисправности на работу автомобиля;
- проанализировать события, предшествовавшие ошибке;
- принять решение о дальнейших диагностических действиях.

:::note
В отличие от плана проверок (ведомого поиска неисправностей), страница DTC не предлагает пошаговых инструкций для диагностики и устранения неисправности, а предоставляет фактические данные для аналитической работы. 
:::

Используйте страницу DTC для следующих задач:
- просмотр детальной информации о коде неисправности, считанном с автомобиля;
- анализ стоп-кадра данных, зафиксированных в момент события;
- переход к пошаговому плану проверок (если доступен).

## Параметры на момент события (стоп-кадр)

Стоп-кадр — это набор дополнительных параметров, сохраненных в момент регистрации DTC. Эти данные играют вспомогательную, но критически важную роль при диагностике.

Параметры на момент события могут быть:
- глобальными — поддерживаются всеми ЭБУ, способными сохранять DTC;
- локальными — специфичны для конкретного ЭБУ и поддерживаются не всегда.

Поддерживаемый набор параметров определяется диагностической спецификацией конкретного блока управления.

### План проверок

Если для данного DTC доступен план проверок, на странице отображается кнопка **Создать план проверок**. <mark>как она работает?</mark>

План проверок — это пошаговое интерактивное описание последовательности действий, направленных на поиск и устранение причины неисправности. 

План проверок может включать в себя:
- инструкции и указания по осмотру, проверкам, замерам деталей и компонентов;
- информацию о расположении деталей и компонентов, вспомогательную графическую информацию (электросхемы, обозначение и нумерация контактов в электрических разъёмах и т.д.);
- считывание данных из электронных систем автомобиля, проведение тестов электронных систем автомобиля;
- оценку результатов осмотров, измерений, тестов;
- рекомендации по диагностике и ремонту.
