# Диагностические коды неисправностей (DTC)

**Диагностический код неисправности** (DTC, Diagnostic Trouble Code) — стандартизированный код, генерируемый бортовой системой самодиагностики автомобиля (OBD-II) при обнаружении неисправности. Код неисправности состоит из буквенно—цифрового идентификатора, где начальная буква указывает на системную область транспортного средства: P — Силовой агрегат, B — Кузов, C — Шасси и U - Сеть (связь).

Диагностические коды неисправностей (DTC) формируются электронными блоками управления (ЭБУ) при обнаружении отклонений от нормального режима работы и используются как отправная точка диагностики — от первичного анализа до выбора дальнейших диагностических действий.

Для работы с диагностическими кодами неисправностей (DTC) автомобиля перейдите в раздел **Список DTC** главного меню DAST. 

На странице **Список DTC** вы можете:
- **считать диагностические коды** всех ЭБУ автомобиля;
- просмотреть **активные и сохраненные** коды неисправностей, сгруппированные по ЭБУ;
- оценить статус, **время и условия регистрации** кодов неисправностей;
- перейти к **детальной информации** по каждому коду неисправности;
- **очистить** диагностические коды.

## Считывание диагностических кодов неисправностей (DTC)

Для считывания диагностических кодов неисправностей всех блоков управления перейдите в раздел меню **Список DTC** и нажмите **Считать DTC**. 

После запуска операции система начинает считывание диагностических кодов **всех электронных блоков управления** автомобиля.

:::tip
Вы можете перейти на другие страницы DAST — операция считывания продолжится в фоне. Считывание диагностических кодов может занять до нескольких минут.
:::

## Список диагностических кодов (DTC)

После считывания диагностические коды отображаются в виде списка, сгруппированного по блокам управления автомобиля (ЭБУ). 

:::note
В списке представлены только блоки с выявленными в ходе считывания диагностическими кодами.
:::

Для каждого блока управления отображается:
- количество обнаруженных диагностических кодов (индикатор рядом с названием ЭБУ);
- список кодов с основными параметрами:
  * диагностический код и его наименование;
  * количество зафиксированных повторений (если доступно);
  * пробег;
  * дата и время;
  * статус («Активная» — выявлена в ходе текущего считывания; «Сохраненная» — выявлена ранее, но не подтверждена в текущем тесте самодиагностикой ЭБУ).

## Удаление диагностических кодов (DTC)

Очистка диагностических кодов используется для:
- проверки, является ли неисправность повторяющейся;
- оценки результатов выполненного ремонта;
- подготовки автомобиля к повторной диагностике.

Чтобы удалить диагностические коды:

1. Перейдите в раздел **Список DTC**.
2. Нажмите кнопку **Удалить DTC**.
