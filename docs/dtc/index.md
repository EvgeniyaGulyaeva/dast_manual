# Диагностические коды событий (ДКС)

**Диагностический код события** (ДКС, DTC, Diagnostic Trouble Code) — стандартизированный код, генерируемый бортовой системой самодиагностики автомобиля (OBD-II) при обнаружении события. Код события состоит из буквенно—цифрового идентификатора, где начальная буква указывает на системную область транспортного средства: P — Силовой агрегат, B — Кузов, C — Шасси и U - Сеть (связь).

Диагностические коды событий (ДКС) формируются электронными блоками управления (ЭБУ) при обнаружении отклонений от нормального режима работы и используются как отправная точка диагностики — от первичного анализа до выбора дальнейших диагностических действий.

Для работы с диагностическими кодами событий (ДКС) автомобиля перейдите в раздел **Журнал событий** главного меню АТОМ ДИС. 

На странице **Журнал событий** вы можете:
- **считать диагностические коды** всех ЭБУ автомобиля;
- просмотреть **активные и сохраненные** коды событий, сгруппированные по ЭБУ;
- оценить статус, **время и условия регистрации** кодов событий;
- перейти к **детальной информации** по каждому коду события;
- **очистить** диагностические коды.

## Считывание диагностических кодов событий (ДКС)

Для считывания диагностических кодов событий всех блоков управления перейдите в раздел меню **Журнал событий** и нажмите **Считать ДКС**. 

После запуска операции система начинает считывание диагностических кодов **всех электронных блоков управления** автомобиля.

:::tip
Вы можете перейти на другие страницы АТОМ ДИС — операция считывания продолжится в фоне. Считывание диагностических кодов может занять до нескольких минут.
:::

## Журнал событий

После считывания диагностические коды отображаются в виде списка, сгруппированного по блокам управления автомобиля (ЭБУ). 

:::note
В списке представлены только блоки с выявленными в ходе считывания диагностическими кодами.
:::

Для каждого блока управления отображается:
- количество обнаруженных диагностических кодов (индикатор рядом с названием ЭБУ);
- список кодов с основными параметрами:
  * диагностический код и его наименование;
  * количество зафиксированных повторений (если доступно);
  * пробег;
  * дата и время;
  * статус («Активный» — выявлен в ходе текущего считывания; «Сохраненный» — выявлен ранее, но не подтвержден в текущем тесте самодиагностикой ЭБУ).

## Удаление диагностических кодов (ДКС)

Очистка диагностических кодов используется для:
- проверки, является ли событие повторяющимся;
- оценки результатов выполненного ремонта;
- подготовки автомобиля к повторной диагностике.

Чтобы удалить диагностические коды:

1. Перейдите в раздел **Журнал событий**.
2. Нажмите кнопку **Удалить ДКС**.

После очистки рекомендуется повторно считать диагностические коды и проверить, выявляются ли они снова.
