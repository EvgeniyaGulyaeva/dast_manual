# Авторизация и доступ

Для работы с системой DAST пользователю требуется действующая учетная запись и доступ к порталу Atom Aftersales.

:::info
Доступ к функциональным возможностям DAST определяется ролью, назначенной Пользователю в системах Атом. 
:::

1. зайти в AS
2. жмать Диагностика
3. откроется окно про Агент
4. скачать Агент и потом жмать Запустить DAST или сразу жмать Запустить DAST, если Агент уже установлен
5. в Агенте запустится DAST
6. и покажет список автомобилей?
