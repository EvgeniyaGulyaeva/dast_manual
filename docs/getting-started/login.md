# Авторизация и доступ

Для работы с системой **АТОМ ДИС** пользователю требуется действующая учетная запись и доступ к порталу послепродажного обслуживания Атом.

:::info
Доступ к функциональным возможностям **АТОМ ДИС** определяется ролью, назначенной пользователю в системах Атом. 
:::

## Авторизация в АТОМ ДИС

1. Перейдите на портал послепродажного обслуживания Атом. 
2. Авторизуйтесь, используя данные своей учетной записи. 
3. Перейдите в раздел **Диагностика**.
4. Если на вашем диагностическом устройстве не установлено приложение АТОМ ДИС, нажмите **Скачать АТОМ ДИС** в открывшемся окне. Если приложение установлено, нажмите **Запустить АТОМ ДИС**.

Для авторизации в **АТОМ ДИС** следуйте инструкциям на экране.

После успешной авторизации приложение отобразит [перечень VIN автомобилей](docs/connection.md), зарегистрированных для сервисного обслуживания в вашем экземпляре **АТОМ ДИС**.
