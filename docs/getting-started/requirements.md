# Требования и меры предосторожности

## Системные требования
### Аппаратные требования

Для работы с системой DAST требуется диагностический кабель OBD-II–Ethernet и диагностическое устройство — персональный компьютер или ноутбук.

**Общие требования к диагностическому устройству**:
- возможность подключения кабеля Ethernet; 
- дисплей с разрешением не ниже 1024×768 (Super VGA);
- 64-битная операционная система на базе Windows.

#### Минимальные и рекомендуемые требования к диагностическому устройству

| Компонент | Минимальные требования | Рекомендуемые требования |
| :------------| :--------------| :---------------|
| **Процессор** | Двухъядерный x64, 1.9 ГГц, с поддержкой SSE2 | Двухъядерный x64, 2.3 ГГц или выше, с поддержкой SSE2 |
| **Браузер** | Chrome 119 / Edge 119 / Firefox 120 | Chrome 121 или новее / Edge 120 или новее / Firefox 122 или новее |
| **ОЗУ** | 512 МБ, доступных для приложения / вкладки браузера | 2048 МБ, доступных для приложения / вкладки браузера |

**Требования к сетевому подключению**

Для работы с DAST в онлайн-режиме требуется стабильное подключение к сети Интернет. В зоне обслуживания должны быть обеспечены следующие параметры сетевого соединения:

| Параметр | Минимальные требования | Рекомендуемые требования |
| :------------| :--------------| :---------------|
| **Сеть** | Пропускная способность 300 Кбит/с, задержка до 150 мс | Пропускная способность 10 Мбит/с, задержка до 50 мс |

### Программные требования

Для работы с DAST необходим DAST Агент — локальное приложение, которое устанавливается на диагностическое устройство и обеспечивает связь между DAST, автомобилем и системой аутентификации и контроля доступа.

При открытии веб-интерфейса DAST вы увидите сообщение о необходимости загрузки DAST Agent. Нажмите **Скачать DAST Agent** и установите приложение. Затем нажмите **Запустить DAST**, диагностический интерфейс откроется в приложении DAST Agent. 

:::note
При первом запуске DAST Agent передает данные о компьютере в систему лицензирования, создается уникальный зарегистрированный экземпляр DAST. При каждом последующем запуске проверяется соответствие текущей аппаратной конфигурации зарегистрированной; при несоответствии может потребоваться повторная активация лицензии. 

Перед выполнением важных диагностических операций система автоматически проверяет:
- активность и срок действия лицензии,
- соответствие идентификатора компьютера лицензии,
- права доступа диагноста.

Только после успешной проверки выполнение операции будет разрешено.
:::

## Требования к квалификации

:::warning
Для работы с системой DAST пользователь должен пройти обучение и получить доступ к системам Атом в соответствии с назначенной ролью.
:::

Основные требования, предъявляемые к квалификации пользователя с ролью «Электрик-Диагност»:
- базовые знания и практические навыки работы с электрооборудованием электромобиля, включая высоковольтные системы;
- базовые знания конструкции современного электромобиля;
- прохождение обучения и сертификации по специальности «Электрик-Диагност Атом»;
- навык использования информационных ресурсов и документации Атом (Руководство по ремонту, Электросхемы, База технических решений, Каталог диагностических кодов неисправностей, Справочник трудоемкостей работ и т.д.);
- наличие соответствующих допусков по электробезопасности (для высоковольтных систем);
- опыт работы по специальности Электрик-Диагност.

## Меры предосторожности

При работе с системой DAST необходимо соблюдать следующие меры предосторожности:

- требования и ограничения, связанные с работой с высоковольтным оборудованием;
- строгое соблюдение инструкций, предупреждений и уведомлений, отображаемых в интерфейсе DAST, а также требований, изложенных в Руководстве по ремонту;
- учет рисков получения травм при активации исполнительных механизмов автомобиля;
- соблюдение правил работы с техническими жидкостями, электрическими компонентами, нагретыми элементами и поверхностями во избежание ожогов, возгораний и повреждений оборудования;
- предотвращение повреждений узлов и компонентов автомобиля при выполнении диагностических процедур;
- использование только исправного и предназначенного для работ инструмента;
- выполнение работ исключительно персоналом, обладающим необходимой квалификацией;
- при возникновении нештатных ситуаций, связанных с продукцией АТОМ (автомобиль, оборудование, программное обеспечение и т.д.) — немедленное обращение в службу технической поддержки.
