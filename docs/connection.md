# Подключение к автомобилю

:::info
Для подключения автомобиля необходим кабель Ethernet-OBD-II (см. раздел [Требования и меры предосторожности](/docs/getting-started/requirements.md)).
:::

## овервью

- запускаем DAST - видим список
- в нем автомобили, зарегистрированные для обслуживания (кем-то как-то где-то)
- в списке показано если кто-то уже работает с автомобилем
- надо выбрать автомобиль из списка (ткнуть в нужный VIN, который можно посмотреть в заказ-наряде или на маркировке), можно поискать по n символов в строке поиска
- почему-то может потребоваться ввести VIN вручную
- в списке показан статус доступа к автомобилю: есть доступ/запросить доступ (как и кем он выдается? как долго действует? как я узнаю, что доступ получен - обновится страница/придет уведомление/надо обновить вручную? может ли тут что-то пойти не так? почему может потребоваться отменить запрос на доступ?)
- если есть доступ и никто не работает, можно сразу подключиться / если доступа нет, надо запросить и подождать пока появится, а потом уже жмать Подключиться (хорошее ли слово "подключиться", ок ли возвратный суффикс?)
- потом ввести номер и код заказ-наряда (которые где-то надо взять)
- там какая-то проверка к чему-то приведет
- воткнуть кабель (сначала воткнуть кабель, потом нажать Продолжить? или vice versa? или неважно?)
- посмотреть на экран прогресса подключения
- готово, жмать Нажать работу
- откроется раздел Об автомобиле
- другим пользователям будет видно, что автомобиль у тебя в работе

## список и выбор из списка

1. После [запуска DAST](docs/getting-started/login.md) пользователь с ролью диагноста получает доступ к списку автомобилей, зарегистрированных для диагностики и обслуживания на данной сервисной станции.

2. Для начала работы **выберите автомобиль из списка**. Идентификация автомобиля осуществляется по **VIN**. Для сверки VIN используйте маркировку на автомобиле или сведения, указанные в документации на сервисное обслуживание.

<mark>при необходимости (какой-то) используйте ручной ввод VIN</mark>

:::note
Автомобиль должен быть зарегистрирован для сервисного обслуживания на конкретной сервисной станции. 
Если автомобиль отсутствует в списке, обратитесь к менеджеру сервисной станции.
:::

## заказ-наряд 

3. Введите номер и код заказ-наряда на обслуживание автомобиля. 

:::tip
номер — n символов, найти их можно ...

код – двухзначное число, найти его можно...
:::

<figure className="img-card">
  <img
    src={useBaseUrl('/img/Connection-Order.png')}
    alt="Ввод заказ-наряда"
  />
  <figcaption>Введите данные заказ-наряда</figcaption>
</figure>

:::note
Перед подключением убедитесь, что **автомобиль не в спящем режиме**. Способ проверки может отличаться в зависимости от модели автомобиля, при необходимости обратитесь к Руководству по эксплуатации или другой документации Атом.
:::

3. Вставьте кабель Ethernet-OBD-II в разъем OBD-II автомобиля.
4. Вставьте кабель в разъем Ethernet диагностического компьютера.  
5. Дождитесь завершения подключения. Текущий статус подключения будет отображен на экране.
6. После успешного подключения нажмите **Начать работу**.
