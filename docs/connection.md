# Подключение к автомобилю

:::info
Для подключения автомобиля необходим кабель Ethernet-OBD-II (см. раздел [Требования и меры предосторожности](/docs/getting-started/requirements.md)).
:::

1. После входа в систему DAST пользователь с ролью диагноста получает доступ к списку автомобилей, зарегистрированных для диагностики и обслуживания на данной сервисной станции.

<figure className="img-card">
  <img
    src={useBaseUrl('/img/Connect-VIN-list.jpg')}
    alt="Список автомобилей, доступных для обслуживания"
  />
  <figcaption>Список автомобилей, доступных для обслуживания</figcaption>
</figure>

:::note
При отсутствии доступных автомобилей система отображает уведомление об отсутствии разрешенных подключений.

<mark>_Автомобиль должен быть зарегистрирован для сервисного обслуживания на конкретной сервисной станции. Регистрация выполняется владельцем автомобиля или иным уполномоченным пользователем на портале Atom Aftersales?. После регистрации автомобиль становится доступным в списке автомобилей для обслуживания_.</mark>

<mark>_Если автомобиль отсутствует в списке, обратитесь к менеджеру сервисной станции (мастеру-консультанту, мастеру цеха)_.</mark>

<figure className="img-card">
  <img
    src={useBaseUrl('/img/No-connection.png')}
    alt="Нет автомобилей, доступных для послепродажного обслуживания"
  />
  <figcaption>Уведомление об отсутствии доступных для послепродажного обслуживания автомобилей</figcaption>
</figure>
:::

2. Для начала работы выберите автомобиль из списка. Идентификация автомобиля осуществляется по VIN.

:::note
Сверка VIN выполняется по маркировке на автомобиле либо по данным, указанным в документации на ремонт.
:::

<figure className="img-card">
  <img
    src={useBaseUrl('/img/Connect-VIN-list.png')}
    alt="Выбор VIN"
  />
  <figcaption>Выбор VIN для подключения</figcaption>
</figure>


<mark>(_нужна ли инфа про заказ-наряд?_)</mark>

:::note
Перед подключением убедитесь, что автомобиль не в спящем режиме. Способ проверки может отличаться в зависимости от модели автомобиля, при необходимости обратитесь к Руководству по эксплуатации или другой документации.
:::

3. Вставьте кабель в разъем OBD-II автомобиля.
4. Вставьте кабель в разъем Ethernet диагностического компьютера.
5. На экране отобразится прогресс подключения.
6. После успешного подключения нажмите **Начать работу**.
