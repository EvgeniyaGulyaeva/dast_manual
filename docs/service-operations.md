# Сервисные операции

Раздел **Сервисные операции** содержит интерактивные пошаговые инструкции для выполнения операций диагностики и обслуживания компонентов автомобиля Атом.

Откройте вкладку **Сервисные операции** главного меню, чтобы увидеть список операций, применимых **ко всем или нескольким блокам управления** автомобиля. 

:::info
Сервисные операции, относящиеся к отдельным блокам управления, можно найти в боковой панели [страницы конкретного ЭБУ](docs/ecu-page.md).
:::

## Выбор сервисной операции

1. Перейдите в раздел **Сервисные операции**.
2. Выберите операцию из списка. При необходимости воспользуйтесь строкой поиска — начните вводить название операции. 

:::tip
Если нужной операции нет в общем списке, перейдите на страницу соответствующего блока управления — операция может быть доступна только для конкретного ЭБУ.
:::

## Выполнение сервисных операций

Каждая сервисная операция содержит подробную пошаговую инструкцию. Выполняйте действия строго в указанной последовательности.

:::danger
Выполнение сервисных операций требует соблюдения особых мер предосторожности. Неукоснительно следуйте инструкциям по подготовке и проведению сервисной операции, представленным в ее пошаговом описании.
:::

1. Выберите сервисную операцию из списка. 
2. Ознакомьтесь с описанием сервисной операции, убедитесь, что в вашем распоряжении есть все необходимые инструменты и вы обладаете достаточной квалификацией для выполнения этой операции. 
3. Нажмите **Начать операцию**.

    alt="Запуск сервисной операции"

4. Выполняйте этапы операции, строго следуя указаниям на экране. 
5. По завершении каждого этапа нажмите **Следующий шаг**, чтобы продолжить выполнение операции.

:::info
Некоторые сервисные операции и отдельные их этапы могут потребовать предварительной подготовки автомобиля или его систем, специальной подготовки рабочего пространства, использования указанных инструментов и других дополнительных действий.

Кнопка **Отменить операцию** прерывает выполнение. После отмены операция получает статус **Прервано**, а информация фиксируется в диагностическом протоколе.

:::warning
Для операций, которые нельзя безопасно прерывать, отмена будет недоступна или система отобразит дополнительное предупреждение. Убедитесь, что приняты все меры безопасности, указанные в инструкции к операции, руководствах по ремонту и обслуживанию, документации производителя и других документах.
:::

## История сервисных операций

Чтобы просмотреть все сервисные операции, выполненные в рамках текущей диагностической сессии, нажмите **История операций** в правом верхнем углу страницы со списком операций.

История помогает:
- понимать, какие операции уже выполнялись и с каким результатом;
- не запускать повторно операцию без необходимости;
- анализировать ход работ при обращении в техническую поддержку (данные фиксируются в диагностическом протоколе).

Для каждой операции отображается статус выполнения в текущей диагностической сессии. 

<mark>такие ли будут статусы? это ли они значат?</mark>

| Статус сервисной операции | Описание | 
|:----|:-----|
| **Не выполнено** | Сервисная операция не выполнялась в рамках текущей сессии |
| **В процессе** | Сервисная операция выполняется в данный момент | 
| **Прервано** | Сервисная операция прервана пользователем в ходе выполнения |
| **Успешно** | Сервисная операция завершена успешно |
| **Не успешно** | Сервисная операция завершена с ошибкой |

:::info
Если в сессии есть операция со статусом «В процессе», завершение диагностической сессии может быть недоступно.
:::
