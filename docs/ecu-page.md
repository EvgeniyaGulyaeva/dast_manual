# Диагностика блоков управления (ЭБУ)

Раздел **Блоки управления** предназначен для просмотра списка электронных блоков управления автомобиля, оценки их текущего состояния и выполнения базовых диагностических действий, связанных с DTC.

  <img

    alt="Раздел Блоки управления"
  />
  <figcaption>Раздел Блоки управления</figcaption>
</figure>

Для каждого ЭБУ в списке отображаются идентификационные данные; примеры отображаемых параметров и их значений представлены в таблице.

| Параметр | Описание | Пример значения |
|:-----| :----- |:------|
| **Код ЭБУ** | Краткое наименование блока (аббревиатура) | BCM, BMS, EPS и др. (см. [Глоссарий](docs/glossary.md)) |
| **Название** | Полное наименование блока | Body Control Module (см. [Глоссарий](docs/glossary.md))|
| **Статус** | Статус подключения блока к сети | <ul><li>В сети — ЭБУ доступен и отвечает</li><li>Не в сети — ЭБУ не отвечает</li></ul> |
| **Версия ПО** | Установленная версия программного обеспечения | 12.25 |
| **DTC** | Информация о наличии диагностических кодов | <ul><li>Считывание не проводилось</li><li>Не обнаружено</li><li>Список кодов DTC (после считывания)</li></ul> |

## Диагностические коды неисправностей (DTC) блока

Чтобы считать DTC **всех блоков управления**, перейдите в раздел **Блоки управления** меню DAST и нажмите **Считать DTC** в верхнем правом углу.

После завершения считывания для каждого блока в таблице будет отображен список обнаруженных DTC или статус «Не выявлено» в случае, если кодов неисправностей в ходе последнего считывания не обнаружено. По умолчанию ЭБУ отсортированы в алфавитном порядке; чтобы просмотреть все блоки управления с выявленными DTC, отсортируйте таблицу по столбцу DTC. 

:::tip
Считывание DTC всех блоков управления также доступно в разделе [**Список DTC**](docs/dtc/index.md) главного меню.
:::

Чтобы считать DTC **отдельного ЭБУ**:
1. Нажмите на строку блока в списке ЭБУ на странице **Блоки управления**.
2. Нажмите **Считать DTC блока** в открывшейся боковой панели. Чтобы перейти на страницу с детальной информацией блока управления, нажмите **Описание и функции** в боковой панели.

<figure className="img-card">
  <img
    src={useBaseUrl('/img/ECU_Sidebar.png')}
    alt="Считать DTC блока"
  />
  <figcaption>Считать DTC блока</figcaption>
</figure>

После выполнения операции:
- отображается список найденных DTC;
- для каждого кода отображается его статус и краткое описание;
- элементы списка подсвечиваются цветом в зависимости от статуса:
    * Активная — неисправность присутствует в данный момент;
    * Сохраненная — неисправность была зафиксирована ранее.

Если при последнем считывании DTC не обнаружены, выводится сообщение «При чтении блока DTC не обнаружено». Если считывание DTC еще не выполнялось, отображается соответствующее уведомление.

:::tip
Чтобы открыть [подробную информацию о коде неисправности](docs/dtc/dtc-info.md), нажмите на элемент DTC в списке.
:::

## Идентификация блока управления

Чтобы просмотреть подробную информацию о блоке управления, перейдите в раздел **Блоки управления** и нажмите на код ЭБУ в списке блоков управления. 

Нажатие на строку блока в списке откроет боковую панель с краткой информацией о блоке; чтобы перейти на страницу ЭБУ, нажмите кнопку **Описание и функции** боковой панели.

## Диагностические операции

На странице блока управления доступны диагностические операции для этого ЭБУ: 
- активация исполнительных механизмов,
- выбор действительных значений для мониторинга,
- сервисные операции,
- тесты.

Для выполнения диагностической операции выберите операцию из списка в боковой панели, выберите параметры операции и следуйте инструкциям.

:::info
В выпадающем списке **действительных значений** боковой панели страницы ЭБУ вы можете выбрать параметры для мониторинга действительных значений. Для просмотра графиков и записи значений перейдите в раздел [**Действительные значения**](docs/live-data.md) главного меню DAST.

Список **сервисных операций** на странице блока управления содержит **только** операции, доступные для выбранного ЭБУ. Чтобы просмотреть операции, применимые ко всем или к нескольким блокам, перейдите в раздел [**Сервисные операции**](docs/service-operations.md) главного меню.
:::

### Исполнительные механизмы 

Диагностика **исполнительных механизмов** предназначена для активации и проверки работы отдельных функций и механизмов, управляемых блоком.

Чтобы активировать механизм:
- Откройте раздел **Исполнительные механизмы** боковой панели на странице ЭБУ.
- Выберите механизм из списка.
- Ознакомьтесь с условиями выполнения и предупреждениями.
- Выполните доступное действие (включение, выключение, переключение режимов).

<figure className="img-card">
  <img
    src={useBaseUrl('/img/ECU-Page-Actuators-select.jpg')}

Перед активацией система автоматически проверяет необходимые предусловия (например, состояние автомобиля, высоковольтной системы, сервисного разъёма). Убедитесь, что все условия и рекомендации выполнены, прежде чем приступать к диагностике исполнительных механизмов.

Во время выполнения операции отображается её текущий статус и результат.
