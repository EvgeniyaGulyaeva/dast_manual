# Диагностика блоков управления (ЭБУ)

Раздел **Блоки управления** предназначен для просмотра списка электронных блоков управления автомобиля, оценки их текущего состояния и выполнения базовых диагностических действий, связанных с ДКС (диагностическими кодами событий).

<figure className="img-card">
  <img
    src={useBaseUrl('/img/ecu-tab.png')}
    alt="Раздел Блоки управления"
  />
  <figcaption>Раздел Блоки управления</figcaption>
</figure>

Для каждого ЭБУ в списке отображаются идентификационные данные; примеры отображаемых параметров и их значений представлены в таблице.

| Параметр | Описание | Пример значения |
|:-----| :----- |:------|
| **Код ЭБУ** | Краткое наименование блока (аббревиатура) | BCM, BMS, EPS и др. (см. [Глоссарий](docs/glossary.md)) |
| **Название** | Полное наименование блока | Body Control Module (см. [Глоссарий](docs/glossary.md))|
| **Статус** | Статус подключения блока к сети | <ul><li>В сети — ЭБУ доступен и отвечает</li><li>Не в сети — ЭБУ не отвечает</li></ul> |
| **Версия ПО** | Установленная версия программного обеспечения | 12.25 |
| **ДКС** | Информация о наличии диагностических кодов | <ul><li>Считывание не проводилось</li><li>Не обнаружено</li><li>Список кодов ДКС (после считывания)</li></ul> |

## Диагностические коды событий (ДКС) блока

Чтобы считать ДКС **всех блоков управления**, перейдите в раздел **Блоки управления** меню АТОМ ДИС и нажмите **Считать ДКС** в верхнем правом углу.

После завершения считывания для каждого блока в таблице будет отображен список обнаруженных ДКС или статус «При чтении блока ДКС не обнаружено» в случае, если кодов событий в ходе последнего считывания не обнаружено. По умолчанию ЭБУ отсортированы в алфавитном порядке; чтобы просмотреть все блоки управления с выявленными ДКС, отсортируйте таблицу по столбцу ДКС. 

<figure className="img-card">
  <img
    src={useBaseUrl('/img/ecu-with-dtc.png')}
    alt="Диагностические коды событий блоков управления"
  />
  <figcaption>Диагностические коды событий блоков управления</figcaption>
</figure>

:::tip
Считывание ДКС всех блоков управления также доступно в разделе [**Журнал событий**](docs/dtc/index.md) главного меню.
:::

Чтобы считать ДКС **отдельного ЭБУ**:
1. Нажмите на строку блока в списке ЭБУ на странице **Блоки управления**.
2. Нажмите **Считать ДКС** в открывшейся боковой панели. Чтобы перейти на страницу с детальной информацией блока управления, нажмите на название блока в списке.

<figure className="img-card">
  <img
    src={useBaseUrl('/img/read-ecu.png')}
    alt="Считать ДКС блока"
  />
  <figcaption>Считать ДКС блока</figcaption>
</figure>

После выполнения операции:
- отображается список найденных ДКС;
- для каждого кода отображается его статус и краткое описание;
- элементы списка подсвечиваются цветом в зависимости от статуса:
    * Активный — код события выявлен последней самодиагностикой;
    * Сохраненный — событие было зафиксировано ранее.

Если при последнем считывании ДКС не обнаружены, выводится сообщение «При чтении блока ДКС не обнаружено». Если считывание ДКС еще не выполнялось, отображается соответствующее уведомление.

:::tip
Чтобы открыть [подробную информацию о коде события](docs/dtc/dtc-info.md), нажмите на код ДКС в списке.
:::

## Идентификация блока управления

Чтобы просмотреть подробную информацию о блоке управления, перейдите в раздел **Блоки управления** и нажмите на код ЭБУ в списке блоков управления. 

Нажатие на строку блока в списке откроет боковую панель с краткой информацией о блоке; чтобы перейти на страницу ЭБУ, нажмите кнопку **Описание и функции** боковой панели.

<figure className="img-card">
  <img
    src={useBaseUrl('/img/view-ecu.png')}
    alt="Боковая панель списка ЭБУ"
  />
  <figcaption>Нажмите **Описание и функции** для перехода на страницу ЭБУ</figcaption>
</figure>

Страница каждого ЭБУ содержит основные сведения о выбранном блоке управления, которые используется для проверки его соответствия автомобилю и конфигурации, а также список ДКС, обнаруженных при последнем считывании.

    alt="Страница блока управления"
  />
  <figcaption>Страница блока управления</figcaption>
</figure>

**Отображаемые данные**

| Параметр | Описание | Пример |
| :----- | :------ | :------- |
| **Название ЭБУ** | Полное и краткое название блока | Body Control Module (BCM) |
| **Номер детали** | Нажмите для перехода в каталог запчастей | 000000381000000 |  
| **Серийный номер** | Уникальный идентификатор блока | BCMATOM1030323000001 | 
| **Дата производства** | Дата изготовления блока | 20.05.2025 |
| **Дата обновления ПО** | Дата последнего обновления ПО блока | 12.02.2025 |
| **Шина** | Тип шины, к которой относится ЭБУ | CAN Entertainment |
| **Статус** | Статус подключения блока к сети | <ul><li>В сети — ЭБУ доступен и отвечает</li><li>Не в сети — ЭБУ не отвечает</li></ul> |
| **VIN** | VIN автомобиля. Сверка VIN необходима для выявления случаев использования деталей автомобилей, а также некорректно выполненных процедур ввода в эксплуатацию. | WFCV1267VVW34R567 |
| **Версия блока данных** | Необходима для сверки версий калибровок ЭБУ с заданными | 123456789012345 |
| **Версия загрузчика** | Может потребоваться для определения применимости ПО | 01.03.01 |
| **Версия АО (Hardware version)** | Может потребоваться для сверки соответствия HW-SW PN, соответствия заданной комплектации | 02.01 |


## Сервисные операции для ЭБУ

На странице блока управления доступны диагностические операции для этого ЭБУ: 
- активация исполнительных механизмов,
- выбор параметров для мониторинга действительных значений,
- сервисные операции,
- тесты.

Для выполнения диагностической операции выберите операцию из списка в боковой панели, выберите параметры операции и следуйте инструкциям. 

<figure className="img-card">
  <img
    src={useBaseUrl('/img/ecu-page-service.png')}
    alt="Выбор диагностической операции"
  />
  <figcaption>Выбор диагностической операции</figcaption>
</figure>

:::info
В выпадающем **списке параметров** боковой панели страницы ЭБУ вы можете выбрать параметры для мониторинга действительных значений. Для просмотра графиков и записи значений перейдите в раздел [**Действительные значения**](docs/live-data.md) главного меню АТОМ ДИС.
::: 

:::warning
Список **сервисных операций** на странице блока управления содержит **только** операции, доступные для выбранного ЭБУ. Чтобы просмотреть операции, применимые ко всем или к нескольким блокам, перейдите в раздел [**Сервисные операции**](docs/service-operations.md) главного меню.
:::
