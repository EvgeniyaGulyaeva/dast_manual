# Завершение диагностической сессии 

После проведения диагностики и обслуживания автомобиля необходимо завершить диагностическую сессию. При завершении сессии диагностический протокол отправляется на сервер.

## Порядок завершения сессии

1. Нажмите **Завершить сессию** в верхнем меню **АТОМ ДИС**. 

:::note
Завершение сессии недоступно, если в сессии выполняется [сервисная операция](docs/service-operations.md) или осуществляется мониторинг [действительных значений](docs/live-data.md). Завершите или прервите все диагностические операции перед завершением сессии.
:::

2. Ознакомьтесь с предупреждением в окне подтверждения. При завершении сессии соединение с транспортным средством будет прервано, а диагностический протокол отправлен на сервер. Отправка может занять некоторое время.

3. Для подтверждения нажмите **Завершить сессию**. Чтобы вернуться к диагностике без завершения сессии, нажмите **Отмена** или закройте окно с помощью кнопки ✕.

4. Дождитесь завершения операции. В процессе завершения сессии **АТОМ ДИС** считает диагностические коды событий с блоков управления, сформирует диагностический протокол (см. [Глоссарий](docs/glossary.md)) и отправит его на сервер. 

:::note
Формирование и отправка протокола занимает до нескольких минут. Не закрывайте окно во время завершения сессии — в таком случае протокол не будет отправлен. При некорректном завершении сессии или неуспешной отправке протокола протокол будет отправлен повторно в начале следующей сессии на этом диагностическом устройстве. 
:::

## Ошибка при завершении сессии

Если при отправке диагностического протокола произошла ошибка, **АТОМ ДИС** отобразит экран с сообщением **«Диагностическая сессия завершена некорректно»**.

В сообщении будет указано, что при отправке протокола произошла ошибка, и предложено повторить попытку или обратиться в службу поддержки.

<figure className="img-card">
  <img

  <figcaption>Ошибка завершения диагностической сессии</figcaption>

Для повторной попытки отправки диагностического протокола нажмите **Повторить**. Если повторная отправка не удается после нескольких попыток, обратитесь в службу поддержки Атом. 

Для завершения сессии без отправки протокола нажмите **Продолжить**. В этом случае, равно как и в случае некорректного завершения сессии, отправка протокола возобновится в начале следующей сессии на этом диагностическом устройстве.
