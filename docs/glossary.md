# Глоссарий

## Глоссарий DAST

| Термин | Определение | 
| :---- | :---- | 
| **Действительные значения<br/>(Диагностические данные в реальном времени, Live data)** | Значения диагностических параметров, получаемых от автомобиля в режиме реального времени |
| **Диагностическая сессия** | Диагностическая сессия — это время работы с автомобилем в DAST. Сессия начинается, когда пользователь подключается к DAST и выбирает заказ-наряд.<br></br>Сессия заканчивается, когда:<ul><li>пользователь вручную завершает ее;</li><li>DAST автоматически завершает найденную незавершенную сессию другого пользователя или другого автомобиля;</li><li>пользователь подтверждает завершение ранее незакрытой сессии для текущего автомобиля.</li></ul>| 
| **Диагностический код неисправности<br/>(DTC, Diagnostic Trouble Code)** | Стандартизированные коды, генерируемые бортовой системой самодиагностики автомобиля (OBD-II) при обнаружении неисправностей. Код неисправности состоит из буквенно—цифрового идентификатора, где начальная буква указывает на системную область транспортного средства: P — Силовой агрегат, B — Кузов, C — Шасси и U - Сеть (связь). |
| **Диагностическое устройство** | Устройство, на которое установлен DAST, позволяющее подключиться к автомобилю проводным и беспроводным способом и используемое для диагностики автомобиля |
| **Заказ-наряд** | Документ, имеющий значение договора на выполнение работ или оказание услуг. Это официальное задание для исполнителя, в котором подробно описываются все требования и условия, необходимые для выполнения задачи, расчета стоимости.| 
| **Исполнительный механизм** | Устройство, которое преобразует управляющий сигнал (обычно электрический) в физическое действие (движение, усилие, переключение) | 
| **Параметры на момент события (стоп-кадр)** | Снимок важных параметров автомобиля и датчиков, сохраненный в момент возникновения диагностического кода неисправности (DTC) | 
| **Портал послепродажного обслуживания** | | 
| **Протокол диагностической сессии** | Электронный документ, в котором DAST регистрирует действия, выполняемые диагностом во время его работы с автомобилем. Протокол также содержит информацию об автомобиле, диагностическом устройстве и зарегистрированных неисправностях и параметрах ЭБУ. Протокол формируется после завершения диагностической сессии. |
| **Сервисные операции** | Интерактивные пошаговые инструкции для выполнения операций диагностики и обслуживания компонентов автомобиля Атом | 
| **Статус неисправности** | Диагностический атрибут, поддерживаемый электронным блоком управления, который отражает состояние неисправности (DTC), включая ее активность, подтверждение и состояние сохранения | 
| **ЭБУ (Электронный блок управления, ECU)** | Электронный блок управления автомобиля, который отвечает за работу одной или нескольких систем автомобиля | 
| **Идентификационный номер (код) транспортного средства (VIN, Vehicle Identification Number)** | Буквенно-цифровая комбинация знаков, устанавливаемая изготовителем для транспортного средства с целью обеспечения должной идентификации каждого транспортного средства |

## Системы и блоки управления автомобиля

| Аббревиатура | Расшифровка |  
| ------------ | :---------- |
| **ACU** | Блок управления подушками безопасности <br/>Airbag Control Unit |
| **ADCU** | Блок управления ассистентами водителя<br/>ADAS Control Unit |
| **AVAS** | Блок управления звуковой сигнализации<br/>Acoustic Vehicle Alarm Unit |
| **BCM** | Блок управления электрооборудованием кузова<br/>Body Control Module | 
| **BMS** | Блок управления высоковольтной аккумуляторной батареей<br/>Battery Management System |
| **BPM** | Дополнительный блок управления электрооборудованием кузова<br/>B-plan module |
| **CBM** | Центральный модуль Bluetooth<br/>Central Bluetooth Module |
| **CGW** | Центральный блок управления коммуникацией<br/>Central GateWay |
| **DCM FL** | Блок управления передней левой двери<br/>Door Control Module Front Left |
| **DCM FR** | Блок управления передней правой двери<br/>Door Control Module Front Right |
| **DCM RL** | Блок управления задней левой двери<br/>Door Control Module Rear Left |
| **DCM RR** | Блок управления задней правой двери<br/>Door Control Module Rear Right |
| **DIM** | Электронное зеркало заднего вида<br/>Digital Interior Mirror |
| **EPS** | Электрический усилитель рулевого управления<br/>Electric Power Steering |
| **ERA** | Модуль ЭРА-ГЛОНАСС<br/>ERA Glonass |
| **EVCOM** | Электрический компрессор системы климат-контроля<br/>Compressor |
| **HLL** | Электроника фары левой<br/>Head Lamp Left |
| **HLR** | Электроника фары правой<br/>Head Lamp Right |
| **HOD** | Датчик распознания рук на руле и подогрев рулевого колеса<br/>Hands off detection |
| **HUD** | Проекционный дисплей лобового стекла<br/>Head-Up Display |
| **HVAC** | Блок управления подогревом и системой кондиционирования<br/>Heating Ventilation Air Condition |
| **IBS** | Блок управления тормозной системы<br/>Integrated Brake System |
| **IVI** | Информационно-развлекательная система автомобиля<br/>In-Vehicle Infotainment |
| **MCU** | Блок управления тяговым электродвигателем<br/>Motor Control Unit |
| **MFP FC** | Многофункцональный дисплей передний центральный<br/>MultiFunction Display Front Central |
| **MFP RC** | Многофункцональный дисплей задний центральный<br/>MultiFunction Display Rear Central |
| **NFC_Tag** | NFC-антенна<br/>Near-Field Communication |
| **PAT** | Регулировка рулевой колонки<br/>Power Adjust Type (Column) |
| **POD** | Блок управления распределением электрического питания<br/>Power On Board |
| **PRND** | Селектор выбора режимов движения<br/>PRND selector |
| **SCUL** | Блок управления сиденьем водителя<br/>Seat Control Unit Left |
| **SCUR** | Блок управления сиденьем пассажира<br/>Seat control unit Right |
| **SGW** | Блок управления системой безопасности коммуникации электромобиля<br/>Security GateWay |
| **Switches** | Подрулевые переключатели<br/>Steering Wheel Switch |
| **SWP** | Дисплей на рулевом колесе<br/>Steering Wheel Panel |
| **T-BOX** | Блок управления телематикой<br/>Telematic Box |
| **TCU** | Блок управления системой терморегулировани<br/>Thermal Control Unit |
| **VCU** | Блок управления электромобилем<br/>Vehicle Control Unit |
| **WCBS1** | Беспроводное зарядное устройство слева<br/>Wireless Charger LH |
| **WCBS2** | Беспроводное зарядное устройство справа<br/>Wireless Charger LR |
