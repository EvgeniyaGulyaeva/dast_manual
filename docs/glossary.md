# Глоссарий

| Термин | Определение | 
| :---- | :---- | 
| **Действительные значения (Live data, Диагностические данные в реальном времени)** | Значения диагностических параметров, получаемых от автомобиля в режиме реального времени |
| **Диагностическая сессия** | Диагностическая сессия — это время работы с автомобилем в DAST. Сессия начинается, когда пользователь подключается к DAST и выбирает заказ-наряд.<br></br>Сессия заканчивается, когда:<ul><li>пользователь вручную завершает ее;</li><li>DAST автоматически завершает найденную незавершенную сессию другого пользователя или другого автомобиля;</li><li>пользователь подтверждает завершение ранее незакрытой сессии для текущего автомобиля.</li></ul>| 
| **Диагностический код неисправности (DTC, Diagnostic Trouble Code)** | Коды, предписанные стандартами SAE, помогающие отслеживать проблемы в автомобиле, обнаруженные его электронными блоками управления |
| **Диагностическое устройство** | <mark>Устройство, на которое установлен DAST, позволяющее подключиться к автомобилю проводным и беспроводным способом.  Используется сотрудником сервисной станции (диагностом) для диагностики автомобиля.</mark> |
| **Заказ-наряд** | Документ, имеющий значение договора на выполнение работ или оказание услуг. Это официальное задание для исполнителя, в котором подробно описываются все требования и условия, необходимые для выполнения задачи, расчета стоимости.| 
| **Исполнительный механизм** | Устройство, которое преобразует управляющий сигнал (обычно электрический) в физическое действие (движение, усилие, переключение) | 
| **Неисправность** | Неисправность, которая может быть обнаружена электронным блоком управления (ECU) и передана в виде диагностического кода неисправности (DTC). Код неисправности состоит из буквенно—цифрового идентификатора, где начальная буква указывает на системную область транспортного средства: P — Силовой агрегат, B — Кузов, C — Шасси и U - Сеть (связь). |
| **Параметры на момент события (Стоп-кадр, Freeze Frame)** | Снимок важных параметров автомобиля и датчиков, сохраненный в момент возникновения диагностического кода неисправности (DTC) | 
| **Портал послепродажного обслуживания** | | 
| **Протокол диагностической сессии** | <mark>Электронный документ, в котором DAST регистрирует действия, выполняемые диагностом во время его работы с автомобилем. Протокол содержит информацию об автомобиле, диагностическом приборе и зарегистрированных ошибках и параметрах ЭБУ. Он используется для определения того, какие операции были выполнены диагностом и с каким результатом. Протокол формируется после завершения диагностической сессии.</mark> |
| **Сервисные операции** | Интерактивные пошаговые инструкции для выполнения операций диагностики и обслуживания компонентов автомобиля Атом | 
| **Статус неисправности** | Диагностический атрибут, поддерживаемый электронным блоком управления, который отражает состояние неисправности (DTC), включая ее активность, подтверждение и состояние сохранения | 
| **ЭБУ (ECU, Электронный блок управления)** | Электронный блок управления автомобиля, который отвечает за работу одной или нескольких систем автомобиля | 
| **VIN (Vehicle Identification Number, Идентификационный номер (код) транспортного средства)** | Буквенно-цифровая комбинация знаков, устанавливаемая изготовителем для транспортного средства с целью обеспечения должной идентификации каждого транспортного средства |

## Системы и блоки управления автомобиля

| **DCM FL** | Door Control Module Front Left / Блок управления передней левой двери |
| **DCM FR** | Door Control Module Front Right / Блок управления передней правой двери |
| **DCM RL** | Door Control Module Rear Left / Блок управления задней левой двери |
| **DCM RR** | Door Control Module Rear Right / Блок управления задней правой двери |
| **DIM** | Digital Interior Mirror / Электронное зеркало заднего вида |
| **EPS** | Electric Power Steering / Электрический усилитель рулевого управления |
| **ERA** | ERA Glonass / Модуль ЭРА-ГЛОНАСС |
| **EVCOM** | Compressor / Электрический компрессор системы климат-контроля |

| **HLR** | Head Lamp Right / Электроника фары правой |

| **HUD** | Head-Up Display / Проекционный дисплей лобового стекла |
| **HVAC** | Heating ventilation Air Condition / Блок управления подогревом и системой кондиционирования |
| **IBS** | Integrated Brake System / Блок управления тормозной системы |

| **NFC_Tag** | Near-Field Communication / NFC-антенна |

| **POD** | Power On Board / Блок управления распределением электрического питания |
| **PRND** | PRND / Селектор выбора режимов движения |
| **SCUL** | Seat Control Unit Left / Блок управления сиденьем водителя|
| **SCUR** | Seat control unit Right / Блок управления сиденьем пассажира |

| **SWP** | Steering Wheel Panel / Дисплей на рулевом колесе |

| **TCU** | Thermal Control Unit / Блок управления системой терморегулирования |
| **VCU** | Vehicle Control Unit / Блок управления электромобилем |
| **WCBS1** | Wireless Charger LH / Беспроводное зарядное устройство слева |
