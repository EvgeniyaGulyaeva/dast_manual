# Глоссарий

## Глоссарий АТОМ ДИС

| Термин | Определение | 
| :---- | :---- | 
| **Действительные значения<br/><br/>Диагностические данные в реальном времени, Live data** | Значения диагностических параметров, получаемых от автомобиля в режиме реального времени. |
| **Диагностическая сессия** | Диагностическая сессия — это время работы с автомобилем в АТОМ ДИС. Сессия начинается, когда пользователь подключается к АТОМ ДИС и выбирает заказ-наряд.<br></br>Сессия заканчивается, когда:<ul><li>пользователь вручную завершает ее;</li><li>АТОМ ДИС автоматически завершает найденную незавершенную сессию другого пользователя или другого автомобиля;</li><li>пользователь подтверждает завершение ранее незакрытой сессии для текущего автомобиля.</li></ul>| 
| **Диагностический код события (ДКС)<br/><br/>DTC, Diagnostic Trouble Code** | Стандартизированные коды, генерируемые бортовой системой самодиагностики автомобиля (OBD-II) при обнаружении неисправностей. Код неисправности состоит из буквенно-цифрового идентификатора, где начальная буква указывает на системную область транспортного средства: P — Силовой агрегат, B — Кузов, C — Шасси и U - Сеть (связь). |
| **Диагностическое устройство** | Устройство, на которое установлен АТОМ ДИС, позволяющее подключиться к автомобилю проводным и беспроводным способом и используемое для диагностики автомобиля. |
| **Заказ-наряд** | Документ, имеющий значение договора на выполнение работ или оказание услуг. Это официальное задание для исполнителя, в котором подробно описываются все требования и условия, необходимые для выполнения задачи, расчета стоимости.| 
| **Исполнительный механизм** | Устройство, которое преобразует управляющий сигнал (обычно электрический) в физическое действие (движение, усилие, переключение). | 
| **Параметры на момент события (стоп-кадр)** | Снимок важных параметров автомобиля и датчиков, сохраненный в момент возникновения диагностического кода неисправности (DTC). | 
| **Портал послепродажного обслуживания** | | 
| **Протокол диагностической сессии** | Электронный документ, в котором АТОМ ДИС регистрирует действия, выполняемые диагностом во время его работы с автомобилем. Протокол также содержит информацию об автомобиле, диагностическом устройстве и зарегистрированных неисправностях и параметрах ЭБУ. Протокол формируется после завершения диагностической сессии. |
| **Сервисные операции** | Интерактивные пошаговые инструкции для выполнения операций диагностики и обслуживания компонентов автомобиля Атом. | 
| **Статус неисправности** | Диагностический атрибут, поддерживаемый электронным блоком управления, который отражает состояние диагностического кода события (DTC), включая его активность, подтверждение и состояние сохранения. | 
| **Электронный блок управления (ЭБУ)<br/><br/>ELectronic Control Unit, ECU** | Электронный блок управления автомобиля, который отвечает за работу одной или нескольких систем автомобиля. | 
| **Идентификационный номер (код) транспортного средства<br/><br/>VIN, Vehicle Identification Number** | Буквенно-цифровая комбинация знаков, устанавливаемая изготовителем для транспортного средства с целью обеспечения должной идентификации каждого транспортного средства. |
